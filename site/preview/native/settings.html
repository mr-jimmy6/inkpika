Settings

Cloud storage

Saved credentials are masked. Leave blank to keep them; enter a value to replace them.

NAS typically uses path style. Connect to S3 interfaces from Garage, SeaweedFS, MinIO / AIStor and similar software. Verify your specific version.

Books and downloads

Must be under /mnt/us/documents. Changing folders or storage sources does not move or delete existing books.

Used by wireless uploads, local book downloads, the cloud library and KUAL sync. Filters by extension; does not convert formats.

e.g. socks5://192.168.1.10:1080 or socks5h://USER:PASSWORD@HOST:PORT. The proxy resolves destination names; URL-encode special characters. Saved proxies are never displayed; leave blank to keep. Applies only to object storage. No direct fallback if the proxy fails.

For a NAS with a private CA, copy the PEM CA certificate to Kindle and enter its absolute path. HTTPS still validates certificates and hostnames.

Configuration is validated before saving. If the cloud library is running, it stops safely and restarts with the saved settings. Resume unfinished downloads manually.
