# InkPika website illustrations

`cloud-library-en.svg` and `cloud-library.svg` are original, editable interface illustrations with synthetic book names. They are not screenshots, device evidence or interactive transfer services. Both use the InkPika name and refer readers to the device compatibility records.

`sync-sample.json` contains public sample snapshots for generating the KUAL demo. The generator reads these fixtures without connecting to a cloud account or device. The interactive preview reuses production HTML/CSS/ES5 and simulates requests inside the browser; it does not establish device compatibility. See [website maintenance](../../../docs/WEBSITE.md).
