## 已通过的本地检查

- `sh scripts/check.sh`：Go race tests、vet、格式、POSIX shell 语法和 22 项 Python 脚本测试。
- KUAL 导航回归：引导菜单和中英文动态菜单的所有子菜单不请求刷新，状态／同步及服务动作保留刷新。
- 新增回归覆盖：配置本机接口的 Host、令牌、Origin、方法和输入校验；LAN 不暴露诊断接口；无线传书不暴露配置；缺少云端账号时仍能读取配置和进入配对。
- `sh scripts/build.sh`：ARMv5 构建、白名单打包、`0.0.1.dev` 版本及 UTC 元数据；两份对象存储文档进入明确白名单。
- 网站样例模型 8 项 Node 测试；中英文浏览器演示检查配置／配对切换、连接测试、书库两页签及版本／UTC 打包时间位于配置表最后两行。浏览器控制台无错误。
- Markdown 本地链接检查；公开文件的个人路径、实际网络地址及图片元数据审阅。公开图片均为合成 SVG，真机截图不发布。

## PW2 已通过的真机检查

- SSH 安装、全部安装文件摘要、已安装二进制 SHA-256、CLI `-version` 与页面/API 构建信息一致。
- 原版 KUAL 顶层仅保留 InkPika 入口；中英文进入 InkPika 后停留超过 10 秒无自动返回。书籍列表、书籍详情、查看状态、后台服务及返回上级均正常；KUAL → InkPika → 配置设置成功启动 WAF。
- WAF `com.inkpika.app` 启动；中英文配置设置页面显示已保存的配置和脱敏密钥，版本与打包时间位于末尾；云端书库显示书库和下载两个页签。
- 配置服务可独立于云端书库启动。通过本机接口执行真实阿里云 OSS HTTPS、目录列举和对象抽样读取，三个阶段通过；不写云端、不创建下载任务。
- 配置独立配对；英文、中文和原偏好保存，运行中的云端服务安全重启；服务端脱敏；无令牌、错误 Origin、配置本机写入和不允许的接口被拒绝；LAN 配置端口不提供连接测试，传书端口不提供配置。
- 真实云端书库列举、独立服务启停；无线配对、测试 TXT 上传、导出内容逐字节一致。仅删除本次测试文件。图书目录整理后逐一核对 21 个图书及附属文件的 SHA-256，保留 10 条同步登记和来源标识；现有图书未丢失。
